Painel Admin - Produto em Promocao

Voltar para a loja

Este painel e uma base inicial para afiliado: voce cadastra o produto, as imagens e o link de compra. O card da promocao na loja e atualizado automaticamente no navegador.

Como inserir novo produto

  1. Escolha se quer criar novo produto ou editar existente.
  2. Preencha titulo, subtitulo, preco antigo e preco atual.
  3. Informe o link de afiliado no campo de compra.
  4. Defina 1 a 3 imagens no formato img/nome-da-imagem.jpg.
  5. Adicione as caracteristicas, uma por linha.
  6. Clique em Salvar produto e depois atualize a pagina da loja.

Se voce selecionar imagem local, ela sera salva junto do cadastro no navegador. Resolucao minima recomendada: 800x800.

Destaque principal da loja

Escolha qual produto deve aparecer no card principal de promocao sem precisar regravar o formulario.

Zona de seguranca

Limpa todos os produtos cadastrados no navegador atual. Essa acao exige confirmacao.

Backup e migracao

Exporte o catalogo atual para JSON e importe no admin de outro dominio. Para que os produtos aparecam automaticamente no Railway apos o deploy, use o botao Salvar Seed de Deploy.

Seed de Deploy: salva o arquivo catalog-seed.json na pasta do projeto. Ao fazer deploy no Railway, o servidor carrega esse arquivo automaticamente se o banco estiver vazio.
